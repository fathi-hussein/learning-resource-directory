# Learning Resource Directory — Sitemap

## 1. Website Structure

The website will consist of three main pages:

```text
                    HOME
                      |
          +-----------+-----------+
          |           |           |
        HOME        EXPLORE      ABOUT
                      |
              RESOURCE CATEGORIES
                      |
              INDIVIDUAL RESOURCES
```

## 2. Page Descriptions

### Home (`index.html`)
- Introduction to the Learning Resource Directory.
- Overview of the platform.
- Navigation to the main sections.
- Featured learning resources.

### Explore Resources (`explore.html`)
- Collection of available learning resources.
- Resources organised into relevant categories.
- Links to external learning platforms.

### About (`about.html`)
- Purpose of the platform.
- Intended audience.
- Brief explanation of the directory.

## 3. Navigation Structure

All three pages will share a consistent navigation menu.

| Navigation Item | Destination |
|---|---|
| Home | `index.html` |
| Explore Resources | `explore.html` |
| About | `about.html` |

## 4. Primary User Journey

1. A visitor opens the homepage.
2. The visitor navigates to Explore Resources.
3. The visitor browses the available resource categories.
4. The visitor selects a resource and follows its external link to the learning platform.
