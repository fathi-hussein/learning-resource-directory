# Project Brief: Learning Resource Directory

## 1. Project Overview

The Learning Resource Directory is a website designed to help learners in Kenya discover educational resources and online learning opportunities.

The platform organises learning resources into categories, making it easier for visitors to explore available opportunities and find resources relevant to their interests.

## 2. Problem Statement

Finding suitable online learning resources can be challenging, particularly for beginners who may not know which platforms offer relevant courses or where to begin.

Information about learning opportunities is often spread across different websites, making the discovery process time-consuming.

The Learning Resource Directory aims to simplify this process by bringing learning resources together in one organised and accessible platform.

## 3. Target Users

The primary users include:

- Students and recent school leavers in Kenya.
- Beginners interested in developing digital skills.
- Individuals looking for accessible online learning opportunities.

## 4. User Needs

Visitors should be able to:

- Discover learning resources in one place.
- Browse resources organised into categories.
- Find relevant learning opportunities.
- Access the original learning platforms through provided links.

## 5. Primary User Action

The main action the website should support is allowing visitors to explore learning resources and navigate to the external platforms offering them.

## 6. Planned Website Pages

### Home
Introduces the platform, explains its purpose, and provides access to the main sections.

### Explore Resources
Displays available learning resources organised into relevant categories.

### About
Explains the purpose of the platform and the audience it serves.

## 7. Interactive Feature

**Search and category filtering**

Visitors will be able to search for learning resources and filter them by category to find relevant opportunities more easily.

## 8. Content and Assets Required

- Website introduction and descriptive text.
- Learning resource names and descriptions.
- Resource categories.
- External links to learning platforms.
- Images and visual assets where appropriate.
- Navigation icons and other interface elements where needed.

Content and assets will be documented in a separate source log. Fictional examples will be distinguished from verified information.

## 9. Technology

- HTML5 for page structure.
- CSS3 for styling.
- JavaScript for interactive functionality in a later development stage.

## 10. Project Scope

The website will be developed incrementally over the six-week internship.

Week 1 focuses on planning the website structure and creating the first semantic HTML page.

Additional pages, responsive layouts, and interactive functionality will be developed in subsequent weeks.

## 11. Project Objective

To create an organised and accessible directory that makes discovering online learning resources easier for learners in Kenya.
